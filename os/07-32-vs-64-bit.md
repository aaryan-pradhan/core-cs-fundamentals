# Lecture 7: 32-Bit vs 64-Bit OS

Common interview question: what do "32" and "64" actually mean, and why is 64-bit better?

**What the 32/64 refers to**

- A CPU chip (embedded on the motherboard) contains billions of transistors, i.e., digital circuits built from gates like NAND/OR.
- From these circuits the CPU has **registers**: locations inside the CPU where the actual computation happens.
  - A register holds data and addresses. E.g., for `1 + 2` in code, `1` and `2` are loaded into registers and then added.
  - Think of a register as a small memory block, or an array of bits.
- A 4-byte register = 4 × 8 = 32 bits. It can hold 4 bytes of data / instruction / information at a time. A 32-bit processor has such 32-bit registers.
- A 64-bit register = 8 bytes. It holds double the data at a time.

```
32-bit register (4 bytes):
| byte 1 | byte 2 | byte 3 | byte 4 |
 bit 0 .......................... bit 31

64-bit register (8 bytes):
| byte 1 | byte 2 | byte 3 | byte 4 | byte 5 | byte 6 | byte 7 | byte 8 |
 bit 0 ................................................... bit 63
```

- CPU 1 with 32-bit registers and CPU 2 with 64-bit registers are two different architectures.
- Hardware comes first; compatible software is built afterwards to run it. The OS that runs on a 32-bit CPU is called a 32-bit OS; the one that runs on a 64-bit CPU is a 64-bit OS.

1. A 32-bit OS has 32-bit registers, and it can access 2^32 unique memory addresses. i.e., 4GB of physical memory.
   - The CPU's job is to go to memory (RAM) addresses and fetch data. RAM is a series of locations with addresses 0, 1, 2, ..., n.
   - Each of the 32 bits can be 0 or 1 (2 values), so 32 bits give 2^32 unique addresses the CPU can locate.
   - 2^32 bytes = 4GB, so a 32-bit CPU can only support up to 4GB RAM. Today even phones have 8GB to 16GB RAM, so this is a big limitation.
   - Addresses, written in hex (4 bytes):

     ```
     first address : 00 00 00 00   (0)
     next address  : 00 00 00 01   (1)
     ...
     last address  : FF FF FF FF   (2^32 - 1)
     ```

2. A 64-bit OS has 64-bit registers, and it can access 2^64 unique memory addresses. i.e., 17,179,869,184 GB of physical memory.
   - To remove the 4GB limit, the register size was doubled to 64 bits, so 2^64 addresses can be located.
   - Addresses run from `00 00 00 00 00 00 00 00` (0) to `FF FF FF FF FF FF FF FF` (2^64 - 1), 8 bytes.
   - This is so much memory that building that much RAM is not practical; doubling the register size was a once-and-for-all fix.
   - Until about the early '90s systems were 32-bit and 4GB RAM was enough. As demand grew, hardware was improved until such large RAM could be supported. The whole move started from RAM.
3. 32-bit CPU architecture can process 32 bits of data & information.
   - Adding two 32-bit numbers is easy on it.
   - Adding two 64-bit numbers (e.g., `int a + b` where the values need 64 bits) on a 32-bit CPU: it first loads and adds one 32-bit half, writes the result somewhere in memory, then works on the other 32-bit half and writes that. So it takes 2 cycles.
4. 64-bit CPU architecture can process 64 bits of data & information.
   - The same 64-bit addition: the CPU loads the whole 0-64 bit operand into its 64-bit register and does the operation (add, subtract, etc.) in 1 cycle.
   - In a CPU, the number of cycles a task takes matters a lot; fewer cycles = better performance.
5. Advantages of 64-bit over the 32-bit operating system:
   - a. **Addressable Memory**: 32-bit CPU -> 2^32 memory addresses, 64-bit CPU -> 2^64 memory addresses.
   - b. **Resource usage**: Installing more RAM on a system with a 32-bit OS doesn't impact performance. However, upgrade that system with excess RAM to the 64-bit version of Windows, and you'll notice a difference.
      - This is an extension of the first point. A 32-bit system cannot use more than 4GB of memory, so the extra RAM stick goes unused.
      - On a 64-bit system, adding another 4GB RAM gets used.
   - c. **Performance**: All calculations take place in the registers. When you're performing math in your code, operands are loaded from memory into registers. So, having larger registers allow you to perform larger calculations at the same time.
      32-bit processor can execute 4 bytes of data in 1 instruction cycle while 64-bit means that processor can execute 8 bytes of data in 1 instruction cycle.
      (In 1 sec, there could be thousands to billions of instruction cycles depending upon a processor design)
      - The CPU is calculating all the time, so calculations being faster on 64-bit matters. 64-bit data is done in one go instead of in 32-bit chunks.
      - The GHz rating (1 GHz, 4 GHz) is how many cycles the CPU does per second. A difference in one cycle multiplies into a big difference per second.
   - d. **Compatibility**: 64-bit CPU can run both 32-bit and 64-bit OS. While 32-bit CPU can only run 32-bit OS.
      - This is backward compatibility: a 32-bit OS on a 64-bit CPU uses only 32 bits of the register, the rest stay 0.
   - e. **Better Graphics performance**: 8-bytes graphics calculations make graphics-intensive apps run faster.
      - Graphics (e.g., games) involve heavy computation: adding/subtracting very large integers. On 64-bit, 8-byte graphics calculations finish in one cycle, double the amount compared to 32-bit, so graphics-intensive apps run faster and more efficiently.

**Interview tip**: Saying 3-4 of these points is enough. The two points you must remember are addressable memory (how much each can address) and how performance is better.
